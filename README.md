# Калькулятор векторов на C++

Консольное приложение для выполнения базовых арифметических операций над двумерными векторами.

## Описание алгоритма

1. **Ввод данных:** Пользователь вводит два вектора в формате `(x;y)` и символ операции (`+`, `-`, `*`).
2. **Парсинг строк (Метод `parseVector`):** Строка очищается от скобок и точки с запятой. Полученные числа считываются в структуру `Vector2D`.
3. **Определение операции (Метод `parseOperation`):** Строка с символом операции конвертируется в перечисление `enum class Operation`.
4. **Вычисления:** С помощью оператора `switch` вызывается соответствующая функция:
   - **Сложение (`+`):** Складывает соответствующие координаты `x` и `y`.
   - **Вычитание (`-`):** Вычитает координаты второго вектора из первого.
   - **Умножение (`*`):** Умножает вектор на скаляр (используется `x`-координата второго вектора).
5. **Вывод:** Результат выводится на экран в формате `(x;y)`.
